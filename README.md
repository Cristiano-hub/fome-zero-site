# Projeto Fome Zero

Este projeto é um site estático (HTML, CSS e JS) que conecta diretamente ao banco de dados Supabase para coletar e exibir feedbacks da comunidade.

## Estrutura
- `index.html` → página principal
- `style.css` → estilos
- `script.js` → lógica de interação com Supabase
- `assets/` → imagens e recursos

## Funcionalidades
- Formulário para envio de feedbacks
- Mural que exibe os depoimentos da comunidade com data e hora automáticas
- Integração com Supabase (Postgres + API)

## Como rodar
Basta abrir o `index.html` no navegador ou publicar em qualquer serviço de hospedagem estática (GitHub Pages, Netlify, Vercel).

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Supabase (Postgres + Auth + API)
